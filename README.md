# band-name-generator-cli

A fun and simple Python command-line tool that helps you generate a band name based on your hometown and your pet’s name.

##  Features

- Takes user input for location and pet name  
- Combines them to create a personalized band name  
- Lightweight, beginner-friendly, and easy to run

##  Example

Welcome to the band name generator
Where are you from?

Berlin
pet name?
Luna
your band name is Berlin Luna
